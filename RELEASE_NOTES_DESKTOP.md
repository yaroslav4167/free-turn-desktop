# FreeTurn Desktop v3.0.10

## Исправления macOS

- Иконка приложения в Dock получила тёмную скруглённую подложку: светлый знак остаётся контрастным на светлом фоне.
- Исправлена ошибка подключения `route: writing to routing socket: Network is unreachable` при добавлении IPv6-маршрутов в utun, если WireGuard-профиль содержит только IPv4-адрес интерфейса, но включает IPv6 в `AllowedIPs`.
- В этом случае helper назначает интерфейсу служебный link-local IPv6-адрес перед установкой маршрутов. IPv6-маршруты профиля сохраняются.
- При первом подключении после обновления macOS один раз запросит пароль администратора для обновления установленного VPN-helper.

## Проверки

Локальная macOS-сборка с обновлённым helper проверена пользователем: подключение VPN работает. Добавлены проверки IPv4/IPv6-адресов и установка IPv6-маршрута на изолированных macOS CI-стендах.

Публикация требует успешных сборок и проверок Windows x64, Linux x64, macOS Apple Silicon и Intel, а также проверки SHA-256 архивов. macOS-сборки подписаны ad-hoc, без Developer ID notarization.
