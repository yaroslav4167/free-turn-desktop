# FreeTurn Desktop v3.0.14

## Windows: проверка прав перед обновлением

- Перед скачиванием и установкой обновления проверяются права администратора. Если FreeTurn запущен без повышения прав, появляется понятная подсказка: закрыть приложение через трей, запустить через «Запуск от имени администратора» и повторить обновление.
- Та же проверка выполняется перед запуском и внутри отдельного установщика. Недостаток прав выявляется до замены файлов и закрытия работающего клиента, а не после ошибки запуска нового EXE `The requested operation requires elevation`.
- Исправлено сообщение об откате: успешное восстановление предыдущей версии больше не сопровождается непонятным `<nil>`. Если сам откат завершился ошибкой, она указывается отдельно.
- Подсказки и новые сообщения доступны на русском и английском. Профили и настройки не меняются. Проверки прав установщиков Linux и macOS остаются прежними.

## Как обновиться со старой версии

Эта правка не может изменить уже запущенный старый установщик. Если предыдущая версия завершала обновление сообщением о необходимости повышения прав, полностью закройте FreeTurn через трей, запустите его **от имени администратора** и повторите обновление. Альтернатива — ручная установка архива из этого релиза.

## Проверки

Добавлены тесты ранней проверки прав до обращения к загрузчику или закрытия окна, запрета запуска установщика без повышения прав и сообщений об успешном/неуспешном откате. Локально прошли Go-тесты desktop; проверка отказа не изменяет установленное приложение.

Публикация требует успешных сборок и проверок Windows x64, Linux x64, macOS Apple Silicon и Intel, а также проверки SHA-256 архивов. macOS-сборки подписаны ad-hoc, без Developer ID notarization.
