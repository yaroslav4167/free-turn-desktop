# FreeTurn Desktop v3.0.13

## Windows: автозапуск и права доступа

- Проверка и настройка автозапуска используют COM-интерфейс планировщика вместо загрузки модуля ScheduledTasks/CIM. Для установленного клиента больше не выполняется лишняя переустановка и перезапись ярлыка при включении переключателя.
- Служебный вывод PowerShell отделён от результата проверки; диагностические сообщения не меняют значение переключателя. Добавлены UTF-8-вывод и явная обработка тайм-аутов.
- При создании задачи задаются рабочая папка, запуск при входе текущего пользователя с повышенными правами, работа от батареи и отсутствие ограничения времени работы.
- При отказе в доступе к Wintun появляется подсказка закрыть FreeTurn и выбрать «Запуск от имени администратора». Техническая причина ошибки сохраняется; подсказка доступна на русском и английском.

## Настройки без повторного ожидания

- Начальная загрузка приложения, выбор профиля и экран настроек используют общий снимок данных и один выполняющийся запрос. При первом открытии настроек после запуска больше не требуется повторно ждать проверки планировщика Windows.
- После изменения параметров снимок обновляется. Запоздавшие ответы не заменяют более новое состояние; после ошибки запрос можно повторить.
- Внешний системный запрос больше не удерживает общий mutex настроек приложения.

## Плавный прогресс обновления

- Диалог обновления и настройки используют единый индикатор вместо платформенного `<progress>`. Полоска плавно переходит между фактически полученными значениями и сохраняет дробные проценты, а текстовый процент остаётся целым.
- До получения размера файла и во время проверки или распаковки отображается отдельное состояние ожидания, без выдуманного процента установки.
- Сохранены доступное описание, корректные ARIA-значения и поддержка уменьшения анимации.

## Имена профилей в ссылках и QR

- Имя из `freeturn://` сразу подставляется в поле импорта. Ручное переименование сохраняется, запоздавший разбор предыдущей ссылки его не перезаписывает.
- При создании и повторной выдаче пользовательской ссылки в `name` записывается имя получателя/устройства, например `mywin`, вместо имени родительского сервера. При пустом имени остаётся прежний резервный вариант — имя сервера.
- Редактирование ссылки VK не меняет имя получателя. Уже выданные ссылки не изменяются автоматически: их можно выдать повторно или переименовать профиль при импорте.

## Проверки

Локально прошли Go-тесты desktop, тесты интерфейса и production-сборка интерфейса. Добавлены проверки Windows-интеграции без изменения реальной задачи автозапуска, кэша настроек, индикатора прогресса, импорта имён и формирования пользовательских ссылок. Ручную проверку переключателя автозапуска после установки новой версии ещё нужно выполнить.

Публикация требует успешных сборок и проверок Windows x64, Linux x64, macOS Apple Silicon и Intel, а также проверки SHA-256 архивов. macOS-сборки подписаны ad-hoc, без Developer ID notarization.
