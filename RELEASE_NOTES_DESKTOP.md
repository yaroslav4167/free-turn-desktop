# FreeTurn Desktop v3.0.5

## Ручная проверка VK

- Исправлена загрузка динамически добавляемых скриптов, стилей, изображений и iframe: адрес переписывается до начала запроса браузером, а не только после вставки элемента в страницу.
- Адреса ресурсов вида `//…` сохраняют HTTPS исходной страницы VK вместо перехода на HTTP локального обработчика. Поддержаны вызовы fetch с объектами Request и URL.
- Перехваты устанавливаются перед скриптами VK также для тега head с атрибутами или в другом регистре.
- Убран принудительный чёрный фон страницы. Если ресурс не загрузился, скрипт VK завершился с ошибкой или виджет остался пустым, показывается пояснение и кнопка обновления страницы. Необязательная реклама не считается отказом captcha.
- Ошибки загрузки попадают в обычный журнал приложения. Подсказка показывает имя хоста, без параметров captcha-ссылки. Страница проверки не кэшируется.

## Если captcha уже не требуется

- Перед решением captcha выполняется один контрольный повтор обычного запроса авторизации с той же идентичностью. Если VK отвечает успешно, подключение продолжается без запуска решателя и без открытия браузера.
- Если VK снова требует проверку, используется свежая captcha из нового ответа. Повтор ограничен одной попыткой на запрос получения токена; ошибки сети не превращаются в успешную авторизацию.
- Отменённая проверка больше не ждёт в очереди за другой captcha и не открывает устаревшую страницу позже. Она также не скрывает чужую активную проверку.
- Контрольный повтор не перезапускает весь VPN и не обрывает работающие потоки. Он не отключает обязательную проверку VK и не гарантирует отсутствие captcha в следующих сессиях.

## Совместимость и проверка

Сохранены профили, ключи, маршрутизация, темы и нативные Linux helper, Windows Wintun и macOS utun/launchd helper. Доступны Linux amd64, Windows amd64, macOS Apple Silicon и Intel. Обновление с v3.0.0–v3.0.4 — напрямую через этот репозиторий.

Публикация требует успешных четырёх нативных сборок, тестов и проверки SHA-256 архивов. Загрузка виджета и ошибки проверены на локальном браузерном макете; это не подтверждение прохождения живой captcha VK или VPN-проверки в каждой ОС. macOS-сборки имеют ad-hoc подпись, без Developer ID notarization.
