# FreeTurn Desktop v3.0.7

## Статусы в трее

- Реализован вариант A: знак FreeTurn с цветным бейджем отключения, подключения, рабочего соединения, проверки VK или ошибки.
- Работающий VPN с ожидающей captcha сохраняет зелёную галочку и получает отдельное жёлтое предупреждение. Подсказка поясняет состояние и число TURN-потоков, без ключей и приватных ссылок.
- Трей обновляется независимо от видимости основного окна, учитывает тему системной панели и доступные настройки уменьшения движения. Анимация используется только при подключении.
- Windows повторяет неудавшиеся обновления и восстанавливает значок после перезапуска Explorer; Linux сохраняет текущий статус при смене темы/перезапуске панели. Активные цветные бейджи macOS не теряют цвет из-за template-тонирования.

## Профили: экспорт, импорт и восстановление

- Экспорт: вкладка «Серверы» → ПКМ по профилю → «Экспортировать профиль…». После подтверждения открывается системный выбор папки и имени файла.
- По умолчанию предлагается `FreeTurn-profile-название.json`, например `FreeTurn-profile-Германия.json`. Имя можно изменить; запрещённые символы заменяются автоматически.
- Импорт JSON — кнопка-иконка с пунктирной рамкой справа от «Добавить сервер». Текст основной кнопки остаётся в одну строку.
- Импорт создаёт новые профили, не заменяя существующие и не запуская VPN или SSH. Файл проверяется целиком до сохранения; лимит — 8 МиБ и 100 профилей.
- Экспорт содержит ключи WireGuard/маскировки и ссылки VK для подключения. **Не публикуйте файл.** SSH-данные и локальные пути к SSH-ключам исключены.
- Добавлена резервная копия предыдущей исправной редакции профилей. При повреждении JSON оригинал сохраняется отдельно; исправная копия восстанавливается автоматически. Без исправной копии приложение открывается с предупреждением, позволяя импортировать профили без затирания повреждённых данных.
- Ручное восстановление доступно в настройках после отключения соединения и подтверждения замены списка.
- Исправлены расхождения памяти и диска после неудачного сохранения/удаления, а также обработка ответов системного подтверждения Windows и GTK, из-за которой не открывался диалог сохранения экспорта.

## Диагностика и прогресс подключения

- Одна кнопка в настройках сохраняет JSON-отчёт с версиями, ОС/архитектурой, наличием VPN-helper, сводкой сетевых интерфейсов, режимов DNS/маршрутизации, счётчиками трафика и до 100 последних изменений состояния.
- Отчёт формируется по списку разрешённых полей: без ключей, паролей, имён/адресов профилей, IP интерфейсов, URL captcha, локальных путей и исходных логов. Внешние запросы для отчёта не выполняются.
- Под кнопкой подключения отображаются фактические этапы: проверка профиля, DNS, списки маршрутизации, запуск адаптера, подключение VK/TURN и настройка маршрутов/DNS. Подключение по-прежнему можно отменить.

## Проверка VK

- Медленная загрузка больше не объявляется отказом через 12 секунд. Через 30 секунд появляется нейтральная подсказка «можно подождать или обновить»; при позднем появлении формы она автоматически скрывается.
- Клик по фону внешнего IUI-диалога не оставляет пустую страницу проверки. Внутренние кнопки, checkbox и ползунок не блокируются.
- На macOS окно доступно через переключатель приложений и не скрывается при потере фокуса. Повторное открытие восстанавливает свёрнутое окно; на Linux сохранена доступность окна в панели задач.
- Изоляция окна, запрет камеры/микрофона/захвата экрана, автоматическая попытка решения до ручной проверки и внешний браузер как запасной способ сохранены.

## Другие исправления

- Исправлен выбор устаревшего профиля автоподключения. Профиль можно выбрать до включения опции; корректный сохранённый выбор не перезаписывается.
- Ошибка автоподключения больше не исчезает при загрузке списка профилей; поздняя ошибка также передаётся в интерфейс.
- Журнал продолжает автопрокрутку после достижения лимита 500 записей, но не возвращает вниз пользователя, читающего старые строки.
- Обновлены документация и демонстрационные снимки интерфейса. Профили, ключи, темы, маршрутизация и нативные VPN-интеграции сохранены.

## Сборки и проверки

Доступны Windows x64, Linux x64, macOS Apple Silicon и Intel. Публикация выполняется только после успешных четырёх нативных сборок, тестов и проверки SHA-256 архивов. Для обновления используются этот репозиторий и `checksums.txt`.

Добавлены проверки транзакций/восстановления профилей, переноса параметров подключения, приватности отчёта, подтверждения экспорта и отмены выбора файла. Синтетические проверки сети покрывают потерю/возврат потоков, captcha при восстановлении и wake-сценарии. Linux smoke-тест запускает настоящий WebView с задержанно появляющейся синтетической формой и проверяет скрытие подсказки, защиту от клика по фону и доступность элементов управления.

**Ограничения:** эти тесты не подтверждают прохождение живой captcha VK, реальную смену Wi-Fi, сон/пробуждение или отсутствие VPN/DNS-утечек на каждой ОС. Диагностический отчёт — локальный снимок, не проверка доступности VPN. macOS-сборки имеют ad-hoc подпись, без Developer ID notarization.
