# FreeTurn Desktop v3.0.0 — прямой переход в общий репозиторий

Установите **v3.0.0 сразу через обновление текущего клиента** — промежуточная
версия не нужна. Здесь размещены те же проверенные архивы, что и в общем релизе:
https://github.com/yaroslav4167/free-turn-desktop/releases/tag/v3.0.0

В бинарники v3.0.0 уже встроен новый источник автообновлений:
`yaroslav4167/free-turn-desktop`. После установки все следующие версии клиент
будет получать оттуда. Профили, настройки и системные VPN-helper сохраняются;
серверы на VPS не изменяются.

Архивы не пересобраны и не изменены при переносе между репозиториями.
SHA-256 в `checksums.txt` совпадает с общим релизом. Для macOS доступны Apple
Silicon и Intel; приложения подписаны ad-hoc, без Apple notarization.

Старые релизы и теги сохранены. Переходные v2.6.6/v1.1.4/v0.2.3 больше не
нужны для обновления: последняя версия в этом репозитории — v3.0.0.
