# Варианты статусов трея

Откройте `index.html`: это самостоятельный интерактивный макет, не часть рабочего
интерфейса и не подключение к настоящему VPN.

[Статичное сравнение вариантов (PNG)](overview.png).

- **A — цветной бейдж:** сохраняет основной знак, статус помещается в углу.
- **B — кольцо:** заметнее состояние подключения, но сам знак становится меньше.
- **C — монохромные метки:** статусы различаются формой, удобно для template-иконки macOS.

Светлая и тёмная панели показывают шесть состояний. Рядом с увеличенным примером
48 px — настоящий размер 20 px. «VPN + captcha» отдельно показывает, что рабочее
соединение не отключено, хотя части потоков нужна проверка.

Ниже можно выбрать состояние для панели предпросмотра и включить анимацию
подключения. По умолчанию она выключена; учитывается `prefers-reduced-motion`.
Макет не меняет приложение, настройки, профили или иконку настоящего трея.

Геометрия знака взята из `desktop/assets/tray-dark.svg`. Происхождение, адаптация
и GPLv3-лицензия визуальных ресурсов описаны в `docs/branding.md`.
