# Окно проверки VK

При активном запросе captcha настольное приложение автоматически открывает
отдельное окно FreeTurn. Не требуется сначала нажимать уведомление или выбирать
браузер. Окно не встраивается iframe в основной интерфейс с доступом к профилям.

## Изоляция

- Используется отдельный режим того же исполняемого файла `--captcha-window`.
  Он обрабатывается **до** запуска обычного приложения: без загрузки профилей,
  VPN, трея, обновлений и без Wails/Go-привязок.
- URL передаётся через stdin, а не в аргументах процесса. Разрешены только
  `http://localhost:8765`, `127.0.0.1:8765` и `[::1]:8765`, без userinfo.
- Linux использует WebKitGTK с ephemeral-контекстом, macOS — WKWebView с
  non-persistent data store, Windows — WebView2 с отдельным временным каталогом.
  Настройки и cookies системного браузера не используются.
- Переходы окна ограничены локальным обработчиком и `about:blank`, новые окна
  блокируются. Мост к функциям приложения отсутствует. В Windows дополнительно
  отключены WebMessage и host objects; разрешения WebView отклоняются.
- Код возврата и короткие сообщения READY/FAILED/EXTERNAL/CLOSED передают только
  состояние окна. Вывод нативного движка не попадает в журнал с приватным URL.

## Жизненный цикл и запасной способ

Один запрос создаёт одно окно; повторное открытие активирует его, а не создаёт
дубликат. После успешной проверки, отмены или отключения окно закрывается.
Если пользователь закрыл его сам, проверку можно открыть вновь из уведомления
в интерфейсе. Работающие VPN-потоки из-за закрытия окна не перезапускаются.

Если WebView недоступен, запуск завис или движок сообщил об отказе загрузки,
текущая проверка автоматически открывается во внешнем браузере. Также доступна
явная кнопка «Открыть в браузере» — в окне проверки и основном интерфейсе.
Это не диалог выбора перед первой попыткой: сначала всегда используется окно
приложения. Отменённая проверка не должна открываться позднее по старому событию.

VK может ограничивать конкретные WebView; исправная загрузка страницы не
гарантирует прохождение живой captcha. Поэтому внешний браузер остаётся запасным
способом.

## Проверки

Тестируются автоматическое открытие, отсутствие дубликатов, запасной переход,
отмена, закрытие, валидация URL и очистка окна без остановки работающих потоков.
В Linux CI отдельный smoke-тест под Xvfb запускает собранный исполняемый файл
с синтетической локальной страницей: проверяет исполнение JS, отсутствие моста
основного приложения, запрет перехода к file:// и закрытие при завершении
управляющего процесса. Он не обращается к VK и не поднимает VPN.
