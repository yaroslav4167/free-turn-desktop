# Логотип и иконки FreeTurn Desktop

За основу взят векторный знак из
[hackdiaz-dev/turn-proxy-android](https://github.com/hackdiaz-dev/turn-proxy-android),
коммит `bab60c5fb620cbea2570eeeb5a0697dc355071f4`.

Исходные ресурсы сохранены без изменений:

- `desktop/assets/branding-source/ic_launcher_foreground.xml` — цветной знак;
- `desktop/assets/branding-source/ic_launcher_monochrome.xml` — одноцветный знак.

Пути в Android-проекте: `app/src/main/res/drawable/`.
Исходный проект распространяет эти ресурсы вместе с GNU GPL версии 3.
Полный текст этой лицензии сохранён в
[android-branding-GPL-3.0.txt](licenses/android-branding-GPL-3.0.txt).
Указанная лицензия сохраняется для исходных и адаптированных визуальных ресурсов;
они не перелицензируются под корневую лицензию кода проекта.

## Выбранное оформление

| Назначение | Файл | Адаптация |
| --- | --- | --- |
| Приложение, ярлык, Dock, favicon | `desktop/assets/icon.svg` | Цветной знак тёмного варианта, без фоновой плитки; сохранены исходные градиенты. |
| Боковая панель и настройки | `desktop/assets/interface.svg` | Плоский светлый знак без подложки. |
| Трей и строка меню | `desktop/assets/tray-dark.svg`, `tray-light.svg` | Плотная одноцветная версия с прозрачным фоном. |

Изменения относительно Android: сняты Android-отступы адаптивной иконки,
удалена фоновая плитка, скорректированы поля и оптическая плотность значка трея.
Цветная и одноцветная геометрия происходят из соответствующих исходных XML.
В Windows используются отдельные многоразмерные ICO для приложения и трея.
В macOS знак строки меню помечается как template: цвет задаёт сама система.
Linux выбирает светлый или тёмный значок с учётом системной темы.

Все PNG, ICO, favicon и копия знака для интерфейса пересоздаются одной командой:

```sh
python3 scripts/render-branding.py
```

Нужен `rsvg-convert` из librsvg. Дополнительные Python-библиотеки не требуются.
Файлы с прежними именами `icon-light.svg` и `icon-light-64.png` оставлены как
совместимые копии нового светлого значка трея, без старой монограммы FT.
