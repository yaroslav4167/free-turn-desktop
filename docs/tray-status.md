# Статусы трея — вариант A

Базовый знак FreeTurn сохранён; состояние передаётся бейджем в правом нижнем
углу. Цвет дополнен формой, а всплывающая подсказка поясняет состояние.

| Состояние | Изображение |
| --- | --- |
| Отключено | Нейтральное пустое кольцо |
| Подготовка / подключение | Синий бейдж с индикатором загрузки |
| Подключено | Зелёный бейдж с галочкой |
| Требуется ручная проверка VK | Жёлтый бейдж с восклицательным знаком |
| VPN работает, но части потоков нужна проверка | Зелёная галочка и отдельный жёлтый треугольник |
| Ошибка подключения | Красный бейдж с крестиком |

Ошибка подготовки нового подключения не делает уже работающий VPN красным:
используется зелёная галочка с предупреждением, а подсказка поясняет причину.
В подсказку не включаются адрес сервера, ключи, ссылка VK или URL captcha.

## Источник состояния

Трей наблюдает за backend и не зависит от открытой страницы интерфейса.
Отдельные признаки подготовки покрывают DNS и запуск VPN-helper до первых
событий ядра. Поколение запроса не позволяет старой отменённой подготовке
заменить состояние нового подключения. Эти признаки не меняют сетевое поведение
и не расширяют публичную JSON-схему состояния.

## Темы, анимация и ресурсы

- Windows и Linux сохраняют выбор контрастного знака по теме системной панели,
  независимо от темы окна приложения. В macOS выбирается знак по виду строки меню.
- Для Linux передаются несколько размеров ARGB-пиктограмм через StatusNotifierItem;
  обновляются `NewIcon` и `NewToolTip`. Перезапуск системной панели сохраняет статус.
- Windows меняет HICON только в потоке окна трея, освобождает предыдущую иконку
  после успешной замены и восстанавливает значок после `TaskbarCreated`.
- AppKit обновляется только через главную очередь; данные PNG копируются из Go
  перед асинхронной передачей. Цветные бейджи не превращаются в template-маску.
- Анимация используется только при подключении; статичные состояния не
  перерисовываются постоянно. Учитываются уменьшение движения macOS,
  `SPI_GETCLIENTAREAANIMATION` Windows и настройки анимаций GNOME/KDE из портала,
  если они доступны. В режиме уменьшения движения остаётся статичный индикатор.
- Растры и PNG кэшируются по состоянию, теме, размеру и ограниченному номеру
  кадра. Растеризатор не читает пользовательские файлы и не выполняет сеть.

## Проверки и предпросмотр

Тестируются приоритет состояний, сочетание работающего VPN и captcha,
локализация подсказок, прозрачность, различимость бейджей в 16–24 px, ограничение
кадров анимации, нативные HICON и D-Bus-уведомления при смене темы/статуса.
Отдельно проверяются ошибки и отмена подготовки до запуска ядра.

Контактный лист из настоящего растеризатора можно получить без запуска VPN:

```sh
FREETURN_TRAY_PREVIEW=/tmp/tray-status-a.png go test ./desktop/tray -run TestWriteStatusIconPreview -count=1
```

На листе сверху — тёмная панель, снизу — светлая; в каждой ячейке 48 и 20 px.
Порядок соответствует таблице выше. Исходный дизайн для сравнения сохранён
в `docs/mockups/tray-status/`; это не скриншот реального подключения.
